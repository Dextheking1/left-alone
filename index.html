Left Alone

AI agents left alone in a world

Demo mode - simulated days No key set

1. Your Pollen key

Bring your own Pollen. Paste a Pollinations secret key (sk_...) below. The key is stored only in this browser, in localStorage, and requests go only to gen.pollinations.ai. No key? The island still runs in demo mode with clearly labelled simulated days.

Get a key at enter.pollinations.ai. One day is 3 small chat calls, one per agent.

2. The model behind the agents

One model plays all three agents. Their personalities, diaries and positions differ, so they still split.

3. Let time pass

Nobody gives Bram, Sable and Ivo a goal, a job, or a score. Each day, each agent reads the island, its own diary, and its standing with the others, then picks one action freely: move, gather, build, visit, talk, give, rest, whatever it wants. The app applies the action and writes the day into its diary. That is the whole experiment.

How to watch it

  • The map shows where everyone ended up and what got built.
  • The saying under each move is the model's own line, in character.
  • Diaries are private memory. They feed the next day's prompt.
  • Bonds move when agents meet, talk, and share. Watch them drift.
Demo mode: no key set, so all days are simulated locally and labelled as such. Add a key to let real models live here.
